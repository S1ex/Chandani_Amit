# Wedding Invitation Website – Shiv & Parvati theme

## Folder structure
```
site/
├── index.html          ← all 8 scenes (page content: names, dates, venue)
├── css/style.css       ← colours, fonts, animations
├── js/script.js        ← countdown, RSVP (WhatsApp), scroll animations
└── images/
    ├── shiv-parvati.jpg   ← ADD: your Shiv–Parvati picture (portrait 3:4)
    ├── ganesh.png         ← ADD (optional): Ganesha image, transparent PNG
    ├── couple-1.jpg       ← ADD (optional): 3 couple photos
    ├── couple-2.jpg
    ├── couple-3.jpg
    └── shiv-parvati-placeholder.svg  (shown until you add your image)
```

## What to edit
1. **index.html** – replace Priya/Rohan, family names, date, venue, event times.
2. **js/script.js** – change `T` (wedding date) and `WA` (WhatsApp number).
3. **images/** – drop in your files with the exact names above.
   Use pictures you have the right to use.

## Go live (free)
Upload the whole folder to Netlify Drop (app.netlify.com/drop), GitHub Pages
or Vercel, then share the link with friends.
